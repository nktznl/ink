# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2024-10-15

### Added
- 📸 **Visual Examples**: Added example.png screenshot demonstrating terminal output
- 📖 **README Enhancement**: Improved documentation with visual preview of library capabilities

## [1.0.0] - 2024-10-15

### Added
- ✨ **Text Styles**: Support for bold, italic, underline, dim, blink, reverse, hidden, and strikethrough
- 🎭 **Advanced Effects**: Rainbow, gradient, and random color effects
- 🏷️ **Themes**: Predefined themes for success, error, warning, info, debug, and trace
- 📝 **Logging Helpers**: Ready-to-use logging functions with icons and automatic theming
- 🔧 **TypeScript**: Full TypeScript support with proper type definitions
- 📦 **Dual Package**: Support for both ESM and CommonJS
- 🏗️ **Build System**: Modern build setup with tsup for bundling
- 🧪 **Testing**: Comprehensive test suite with Jest
- 🎨 **Linting & Formatting**: ESLint and Prettier configuration
- 🚀 **CI/CD**: GitHub Actions workflow for automated testing and publishing
- 📚 **Documentation**: Comprehensive README with examples and API reference

### Changed
- 🎯 **API Enhancement**: Improved chaining API with better type safety
- 📦 **Package Structure**: Updated to modern package.json with exports field
- 🎨 **Code Quality**: Added strict linting and formatting rules

### Fixed
- 🐛 **Type Safety**: Resolved TypeScript strict mode issues with proxy-based API

### Removed
- ❌ **Legacy Support**: Dropped support for older Node.js versions (<14.0.0)

## [0.0.1] - 2024-01-01

### Added
- 🎨 Initial release with basic ANSI color support
- 🔗 Chaining API for combining colors
- 📝 Basic documentation and examples
